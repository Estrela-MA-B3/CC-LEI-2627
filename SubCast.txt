FLAGS
1) UDP Request 1 bit - A 1 se estiver a pedir que o broker envie a porta UDP dele
2) Publisher/Subscriber 1bit - A 1 se for publisher e a 0 se vier de um subscriber 
3) Registo/subscrição 1bit - A 1 se deseja efetuar um registo ou uma subscrição do que vem a seguir (so depois de estabelecer sessao) / Para confirmar o registo 
4) Cancelamento subscrição 1bit - A 1 se estiver a vir de um subscriber (bit a 0) e ele estiver a identificar o cancelamento de uma subscrição / Para confirmar o cancelamento
5) Terminação 1bit - A 1 se estiver a ser informado que o publicador/subscritor vai terminar / Para confirmar que eliminou todos os ficheiros associados
6) QoS - QoS = 1 -> bit a 0 ; QoS = 2 -> bit a 1
7) N/A
8) N/A
TamanhoTotal: Tamanho total dos dados enviados da camada aplicional (cabeçalho+payload)

Tópico(binário): que é algo sobre este formato X/Y/Z - que se for totalmente especifico é north/station7/temperature ou pode ser abrevidado para especificar mais do que um conjunto de dados usando *, ou seja, north/station7/*.
